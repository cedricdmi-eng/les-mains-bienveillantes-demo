# Les Mains Bienveillantes — Démo statique

Cette version est une maquette codée HTML/CSS/JS, pensée pour être publiée très facilement sur Cloudflare Pages.

## Déploiement Cloudflare Pages

### Option la plus simple : GitHub
1. Créez un nouveau dépôt GitHub.
2. Déposez `index.html`, `styles.css` et `script.js` à la racine.
3. Dans Cloudflare : Workers & Pages → Create → Pages → Connect to Git.
4. Sélectionnez le dépôt.
5. Framework preset : **None**
6. Build command : laissez vide.
7. Build output directory : `/`
8. Déployez.

Cloudflare créera une URL en `*.pages.dev`.
